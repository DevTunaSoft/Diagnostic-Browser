Safety limitations

Windows crash-log integration, complete worker auto-attachment, robust automatic repair, Windows acceptance and OS-isolated offline AI are not yet verified. SQLCipher is mandatory for normal operation and must pass on-device testing.

Fully local evidence interpretation

Uses only sanitized, locally retained technical metadata. The model cannot access Chrome, the CDP connection, or raw browser messages. AI findings are hypotheses, not verified root causes.

Bundled Chromium engine

CHECKING

The browser engine ships with the application. Updates are installed into a per-user, writable location that overrides the read-only bundled copy — the signed application is never modified. Downloads use Playwright's pinned, hash-verified Chromium from its official distribution only; the sandbox and capture policy are never weakened, and no downgrade below the security floor is permitted.

Engine status not yet loaded.

Why in-app updates

A browser is a security-sensitive component. In-app updating lets you move to a newer hardened Chromium build between full installers, with the same pinned, verified source the installer uses. The running session keeps its current engine; the new build is used on the next browser launch.
