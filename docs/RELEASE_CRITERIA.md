# Release acceptance criteria

This is a public, vendor-neutral project. Publication is blocked until all of the following have actual evidence:

1. Integrated browser and diagnostics GUI is implemented and exercised.
2. A single Windows `DiagnosticBrowser.exe` contains all runtime components and offline AI model; no first-run downloads or installed browser/runtime required.
3. Clean Windows VM launches and navigates without development tools.
4. Offline recording, encrypted storage, privacy filtering, incident export, recovery, and restart pass integration tests.
5. Security and malformed-input tests, fault injection, lifecycle tests, and extended soak complete with recorded results.
6. No proprietary identifiers or sensitive records in source, resources, metadata, binaries, or reports.
7. Reproducible build artifacts, hashes, dependency licensing review, and release notes are provided.

**Current status: blocked.** The initial repository is a safe public scaffold, not a finished release.
